# Security Policy

This repository distributes static OpenCode skill files (.md) and Bash helper scripts. There are no compiled binaries, no network-facing services, and no dependency supply chain beyond the skill files themselves.

**Concerns about the skill content or helper scripts?** Open an issue or pull request. There is no dedicated security contact; the [GitHub issue tracker](https://github.com/anomalyco/opencode/issues) is preferred for all reports.

**Concerns about credentials or secrets embedded in the repository:** See `.gitignore` and review the git history. No active credentials are stored in this repository. If you find exposed secrets in historical commits, please report via issue — rotate any potentially compromised credentials regardless.
